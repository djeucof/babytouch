# 👶🏼🫧 Baby Touch 👉🏻🫧
Minimalist sensory touch web game for babies with adaptive Web Audio &amp; HTML5 Canvas. Built for calm, anti-overstimulation UX.

✨[ **Play Baby Touch Live**](https://djeucof.github.io/baby-touch/) ✨

---
## 🤷‍♂️ What is this?
It's a digital panic room for your screen. 

Tap anywhere $\rightarrow$ get a soft pastel bubble, a smooth fade-out, and a gentle musical note. Bottom of the screen gives you warm bass notes; top of the screen sounds like a tiny digital harp. No menus. No ads. No existential dread.

---

## 🛠️ Tech Stack
* **Frontend:** Vanilla JavaScript, HTML5 Canvas API.
* **Audio:** Web Audio API (real-time sine wave oscillator synthesis — zero heavy audio files, zero loading lag).
* **Deployment:** GitHub Pages.
